# 岗位数据采集与审核流程

## 数据要求

至少准备 20 条真实岗位数据，每条记录建议包含：

| 字段 | 说明 |
| --- | --- |
| `title` | 岗位名称 |
| `company` | 公司名称 |
| `location` | 工作地点 |
| `publish_time` | 发布时间 |
| `skills` | 技能关键词 |
| `source_link` | 来源链接 |
| `updated_at` | 本系统更新时间 |
| `status` | `pending`、`approved`、`rejected` |

## 业务流程

```text
采集/手动导入 -> 字段校验 -> 技能提取 -> 去重 -> pending -> 人工审核 -> approved/rejected -> approved 数据进入匹配和向量库
```

## 审核规则

- 标题、公司、地点、发布时间、来源链接不能为空。
- 来源链接应能追溯到真实岗位页面。
- 技能字段不能只写“计算机”“办公软件”等过泛内容。
- 重复岗位保留更新时间较新的记录。
- 薪资、学历、经验要求如果来源中存在，后续可以作为扩展字段。

## 可展示证据

- 原始岗位数据文件或截图。
- 清洗前后字段对比。
- 审核列表页面，能看到 `pending`、`approved`、`rejected`。
- 被拒绝数据的拒绝原因。
- 通过审核的数据进入岗位匹配结果。
