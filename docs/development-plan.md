# 第一阶段开发计划

## 阶段 1：项目骨架

- 初始化仓库结构。
- 搭建 FastAPI 后端和 React 前端。
- 预留岗位、简历、匹配、面试、管理端接口。
- 写清楚分支规范和每人负责边界。

## 阶段 2：数据与审核

- 准备至少 20 条真实岗位数据。
- 完成岗位字段校验、技能提取、去重。
- 实现 `pending`、`approved`、`rejected` 状态流转。
- 审核通过的数据进入匹配流程。

## 阶段 3：智能功能

- 简历审核：模糊表达、关键词缺失、项目描述不完整、夸大风险。
- 岗位匹配：技能相似度、岗位要求覆盖率、推荐原因。
- 面试 Agent：简历分析、岗位问题生成、回答评分反馈。

## 阶段 4：联调与交付

- 前后端联调。
- 补充测试记录：正常、失败、异常。
- 完成报告、PPT、演示视频和项目日报。
- 打最终标签 `v1.0.0-final`。
