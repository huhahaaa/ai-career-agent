## 三、当前最需要补齐的内容

1. 简历版本对比：展示不同版本的匹配分数、命中技能、缺失技能和修改建议变化。
2. 岗位收藏与投递状态：让用户可以收藏岗位、记录投递状态，并在看板中汇总。
3. 多模态面试报告：把摄像头、语音识别、语速、停顿、视线和姿态分析写入最终报告。
4. 评分校准展示：增加人工评分字段，对比 Agent 评分、规则评分和人工评分的偏差。
5. 岗位来源检查：补全来源可用性检查、过期检测和定时更新记录。
6. 知识库引用增强：匹配和面试结果不仅展示岗位来源链接，还应展示命中的岗位能力模型、题库或知识片段来源。
7. 最终交付材料：补齐测试截图、失败案例、演示视频、PPT、项目报告和 Git 记录导出。
