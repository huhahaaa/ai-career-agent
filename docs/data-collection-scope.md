# 岗位数据采集范围与审核口径

## 采集目标

本批数据服务于“AI 面试陪练、简历优化与岗位匹配 Agent”。第一版覆盖六类岗位，每类 4 条，共 24 条公开岗位页面：

- 前端开发
- 后端开发
- 产品经理
- 运营
- 算法/机器学习
- 数字媒体/内容

采集时间：2026-07-24（Asia/Shanghai）。

## 来源原则

1. 优先使用公司官方招聘页或公司使用的官方 ATS 页面。
2. 保存岗位标题、公司、地点、岗位要求、来源链接和采集时间。
3. 不绕过登录、验证码、访问控制或付费限制。
4. 页面可访问只代表数据来源可追溯，不代表岗位在答辩当天仍接受投递；演示前应重新检查岗位状态。
5. 公开页面中的个人联系方式不进入数据集；本批数据只保留岗位信息。

## 审核口径

岗位进入 `approved` 的条件：

- 岗位名称、公司名称、岗位正文和来源链接不为空；
- 能提取至少 3 个技能或能力标签；
- 来源链接可访问，且页面内容与岗位标题一致；
- 未发现完全重复记录；
- 未发现明显乱码、广告文本或个人隐私信息。

`approved` 表示“数据质量审核通过”，不等于承诺岗位当前仍在招聘。发布日期未明确的岗位会在审核意见中标记，供演示前复核。
