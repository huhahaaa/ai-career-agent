## 2. Agent 组员

### 负责人

Agent / 简历面试模块负责人

### 今日任务

1. 将面试 Agent 拆成多种模式：
   - HR 面
   - 技术面
   - 压力面
   - 反馈教练
2. 优化 Prompt，要求 Agent 不输出 Markdown 符号，避免报告里出现 `**`、`---`、`#` 等原始格式。
3. 优化评分反馈结构，让每轮反馈包含：
   - 得分
   - 优点
   - 问题
   - 改进建议
4. 整理 30 个面试题库 JSON，按岗位或题型分类。
5. 增加低质量回答、回答过短和信息不足时的测试案例。

### 建议提交

```text
feat(agent): 增加多面试官模式
feat(agent): 优化评分反馈结构
data(interview): 增加岗位面试题库
fix(agent): 规范报告输出格式
test(agent): 增加低质量回答测试案例
```

### 今日验收标准

- 面试页或接口能选择不同面试模式。
- 评分反馈比第一天更结构化，能清楚看到分数、优点、问题和建议。
- STAR 建议和练习计划不再输出未渲染的 Markdown 符号。
- 题库 JSON 可以在报告中作为“面试题库数据”说明。

## 3. 向量 / 匹配组员

### 负责人

向量检索 / 岗位匹配模块负责人

### 今日任务

1. 将岗位能力模型、技能词典、面试题库接入知识库。
2. 优化匹配结果，让每条匹配结果增加：

   - 引用来源

   - 待检查

### 建议提交

```text

```

### 今日验收标准

- 匹配结果不只显示分数，还能解释“为什么匹配”和“缺什么能力”。
- 页面或接口能展示岗位来源链接或知识库引用来源。
- 知识库材料可以对应到报告中的“岗位能力模型、面试题库和行业规范”。
