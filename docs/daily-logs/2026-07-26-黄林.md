## 四、遇到的问题

1. 问题：直接从仓库根目录运行单个后端测试时，测试配置无法导入 `app`。
   - 原因：后端测试需要把 `backend` 加入 Python 导入路径。
   - 解决方法：从 `backend` 目录运行单个测试；运行完整测试时设置 `PYTHONPATH=backend;.`。

2. 问题：部分岗位页面没有具体发布日期。
   - 原因：不同公司的 Greenhouse/Ashby 页面公开字段不一致。
   - 解决方法：保留“未标注”，记录来源链接和最近核验日期，不自行猜测发布日期；演示前重新复核页面状态。

3. 问题：当前环境没有安装 GitHub CLI `gh`。
   - 影响：可以正常推送分支，但可能无法在命令行自动创建 PR。
   - 解决方法：先完成分支推送；如果工具不可用，提供 GitHub PR 创建链接供手动提交。
