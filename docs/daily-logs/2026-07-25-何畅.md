## 四、遇到的问题

1. 问题：多岗对比页面只能显示固定两个岗位，且岗位选择布局较混乱。
   - 原因：前端最初使用静态对比数据和固定展示结构，没有完全接入已审核岗位列表。
   - 解决方法：改为从已审核岗位中自由选择多个岗位加入对比，并整理选择区布局和字段展示。

2. 问题：部分岗位薪资、经验、学历字段显示为“未填写”，薪资未公开岗位还会以 0k 进入图表。
   - 原因：清洗数据字段未完全同步到前端展示层，薪资图表没有排除“未公开”数据。
   - 解决方法：同步清洗岗位完整字段，前端对缺失字段使用“未公开 / 未标注”，并过滤无薪资岗位的图表数据。

3. 问题：岗位匹配分数普遍偏低，不能体现“大方向、语言、框架、工具”之间的层级关系。
   - 原因：早期评分更偏向原始向量相似度和简单技能命中，不适合直接当百分制业务分数。
   - 解决方法：增加分层能力评分，将方向匹配、语言匹配、框架工具匹配和语义相似度综合校准。

4. 问题：简历审核和测试快照混在一起，导致数据看板技能画像和简历数量可能被测试数据干扰。
   - 原因：用户粘贴简历参与匹配或面试时，后端会自动保存快照，但之前没有区分正式简历和测试快照。
   - 解决方法：增加正式简历、测试快照和默认主简历概念，看板优先统计主简历，匹配和面试支持选择具体简历。

5. 问题：语音输入、摄像头姿态提示和面试统计存在体验细节问题。
   - 原因：浏览器语音识别状态、摄像头提示文本高度、未完成面试统计过滤等逻辑需要继续细化。
   - 解决方法：修复语音输入触发逻辑、统一摄像头提示区高度，并排除未完成面试对次数和平均分的影响。
