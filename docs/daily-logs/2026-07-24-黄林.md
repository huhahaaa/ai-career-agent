## 四、遇到的问题

1. 问题：部分招聘页面没有标注具体发布日期，且岗位页面可能随招聘状态变化。
   - 原因：不同公司招聘系统公开字段不一致。
   - 解决方法：保留“未标注”状态，记录来源链接和采集时间，并在审核意见中要求演示前复核。

2. 问题：仓库最初是只克隆 `黄林` 分支，本地没有 `origin/main` 引用。
   - 原因：克隆时使用了单分支模式。
   - 解决方法：获取远程 `main` 并建立本地 `main` 引用，确认主分支项目结构后按其数据目录接入。

3. 问题：当前 Python 环境缺少部分测试依赖。
   - 原因：没有预先安装项目 `backend/requirements.txt` 中的完整依赖。
   - 解决方法：补充 pytest、python-jose 和 email-validator 等依赖，最终完成 13 个后端测试。
